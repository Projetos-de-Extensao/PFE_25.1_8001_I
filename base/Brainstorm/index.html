Introdução

O brainstorm é uma técnica de elicitação de requisitos que consiste em reunir a equipe e discutir sobre diversos tópicos gerais do projeto apresentados no documento problema de negócio. No brainstorm o diálogo é incentivado e críticas são evitadas para permitir que todos colaborem com suas próprias ideias.

Metodologia

A equipe se reuniu para debater ideias gerais sobre o projeto via Discord, começou 15:50 e terminou 17:20, onde o Arthur Riess Cunha foi o moderador, direcionando a equipe com questões pré-elaboradas, e transcrevendo as respostas para o documento.

Brainstorm

Versão 1.0

Perguntas

1. Qual o objetivo principal da aplicação?

1 - Compra e visualização simples de ingressos.

2 -O principal objetivo seria uma forma dos clientes comprarem ingressos de forma segura e rapida

3 - Compra e vendas de ingressos

4 - Principal objetivo da aplicação é facilitar o cliente na compra de ingressos para eventos.

2. Como será o processo para cadastrar um novo clientetorneio?

1 - O cliente vai apertar num botão de login 2 - O cliente vai fazer o login com seu email e senha anteriormente cadastrados --- ### 3. Como será a forma de adicionar produtos?

1 - O moderador adicionará os produtos no site

2 - O usuário poderá visualizar os produtos na homepage

3 - O usuário poderá comprar os produtos --- ### 4. "Outras perguntas pertinentes ao contexto", Como seria a forma de adicionar do cliente adicionar os produtos ?

1 - Será criada uma área para produtores ou colaboradores acessarem

2 - O cliente vai preencher um formulário com informações pessoais

3 - O cliente vai adicionar também as informações do evento (Horário, localização, público esperado...)

--- ### 5. Quais informações seriam interessante para o cliente?

1 - Filtro de busca por localização 2 - Filtro de busca por clube 3 - O usuário poderá ver scouts de partidas do torneio, ver as regras dos torneios, locais e data das partidas.

Através da aplicação do brainstorm, foi possível elicitar alguns dos primeiros requisitos do projeto, clarificando para a equipe como devemos desenvolver as funcionalidades do nosso site.
